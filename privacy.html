Privacy Policy

Last updated: September 24, 2026

1. Overview

Personal Automation Assistant is a private personal automation application powered by OpenClaw and used by its owner for personal productivity workflows. It is not a public SaaS product or a service sold or offered to other users.

This policy describes how the application handles Google user data. This public information website can be viewed anonymously and uses no login, cookies, analytics, or third-party tracking.

2. Google User Data

The application can access Google user data only after the Google Account owner explicitly authorizes access through OAuth. The data available depends on the permissions granted and the requested workflow, and may include:

  • Gmail messages and related information.
  • Google Calendar calendars and events.
  • Google Drive files and related information.
  • Google Docs document content.
  • Google Sheets spreadsheet content.
  • Google Contacts contact information.

3. How Google User Data Is Used

Google user data is used only to perform automation explicitly requested by the user. This may include working with messages, scheduling events, organizing files, updating documents or spreadsheets, or managing contacts, within the permissions granted by the account owner.

4. Data Storage

Google user data may be processed or temporarily stored on systems controlled by the application owner while automation is performed. Any retained data is kept only as needed for the requested workflow and can be the subject of a deletion request as described below.

This public static website does not receive or store Google user data or OAuth credentials.

5. Data Sharing

Google user data is not sold. It is not shared with third parties unrelated to the application's functionality. Any transfer needed to carry out a user-requested workflow is limited to that purpose and subject to the Google API Services User Data Policy, including its Limited Use requirements.

6. Advertising

Google user data is not used for advertising, ad targeting, or advertising profiles.

7. Google API Services User Data Policy

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Revoking Access

The account owner can revoke access at any time through Google Account Security settings. Visit Google Account connections, select this application, and remove its access.

Revoking access prevents further authorized access through that connection. It does not automatically delete data already stored by the application; stored data can be addressed through a deletion request.

9. Data Deletion

To request deletion of related Google user data stored on the application owner's systems, contact the application owner using the address below. Identify the account and the data concerned, but do not send passwords or access tokens. The owner will review the request and delete the related stored data after confirming the request is authorized.
